# Implementation decisions

## Step 1 scope

Set up an isolated Python environment, install dependencies, establish folders and record experiment settings. The first milestone contained no dataset downloads, ML training or web interface. The user subsequently approved committing and pushing the verified setup.

## Baseline methods

Preserve the team repository's seven features per channel: mean, standard deviation, variance and mean Welch PSD in delta [0.5,4), theta [4,8), alpha [8,13) and beta [13,30) Hz bands. The feature count is 161 only for an aligned 23-channel input. The original code does not include RMS and does not integrate PSD over each band.

Keep StandardScaler and balanced Logistic Regression. The source uses max_iter=1000, an 80/20 stratified random split (seed 42) and a threshold of 0.4. These historical settings are recorded, not evidence of generalization. Threshold selection belongs on validation data.

## Conflicting preprocessing sources

The inspected repository specifies a 0.5-40 Hz band-pass and 50 Hz notch. The chat/sample slides specify 0.5-50 Hz and 60 Hz. Both are named profiles in the configuration. The repository profile is the reproduction reference, not an endorsed final filter choice. Before processing real recordings, inspect dataset acquisition details, channels and the need for a notch after band-pass filtering.

Average referencing is deferred until montage inspection. A channel count of 23 and sampling rate of 256 Hz must not be hardcoded for arbitrary uploaded files.

## Labeling and validation decisions pending Step 2/3

- Recover labels from official seizure annotations; the referenced labeling module was absent from the accessible source listing.
- Define complete-window inclusion, seizure/postictal exclusion intervals and boundaries explicitly.
- Preserve timestamps, recording identifiers and patient identifiers with features.
- Prevent overlapping signal from crossing splits. Primary evaluation is recording-grouped, with patient-grouped evaluation when the dataset supports it.
- Never fit scalers, resampling or feature selection on validation/test data.
- SMOTE appears in the sample slides but not the inspected training script; it is not part of the initial baseline.

## Intensity and application

There are no supplied intensity ground-truth labels or approved severity definitions. A later module may describe experimental EEG signal intensity with a documented reference and limitations. It must not map seizure probability directly to mild/moderate/severe clinical labels.

Streamlit will wrap the same saved preprocessing/feature/model contract used for inference. Real-time demonstration means recorded-data playback until a causal streaming pipeline is separately implemented and tested.

## Historical results

The main presentation reports TN=244, FP=20, FN=2 and TP=22 for 288 test windows. Those are supplied historical results, not reproduced results of this repository. All new metrics must be generated by recorded experiments.

## Step 2 observations

The real-data inspection and source citations are recorded in STEP_2_DATA.md. The official summary resolves the missing annotation source. Two identical T8-P8 traces require an explicit channel-selection decision in Step 3. Only one seizure is in the initial sample, so more events are required before independent train/validation/test evaluation.

band-pass and 60 Hz notch. The experiment runner rejects other algorithms.

changing TOML alone does not migrate an already trained model.

identical duplicate, while the supplied description says 23 channels and average
